Порты, которые спрашивают

Базовые команды Cisco IOS

enable — привилегированный режим
configure terminal — режим конфигурации
hostname R1 — имя устройства
interface gi0/0 — перейти к интерфейсу
ip address 192.168.1.1 255.255.255.0
no shutdown — поднять интерфейс
ip route 0.0.0.0 0.0.0.0 10.0.0.1 — маршрут по умолчанию
show ip interface brief — что поднято и с какими адресами
show running-config — текущая конфигурация
copy running-config startup-config — сохранить
show ip route — таблица маршрутизации
show mac address-table — таблица MAC коммутатора
vlan 10 / name Class — создать VLAN
switchport mode access / switchport access vlan 10
switchport mode trunk — транк между коммутаторами

Диагностика с рабочей станции

ping 8.8.8.8 — есть ли связь вообще
ping ya.ru — работает ли DNS
tracert / traceroute — на каком узле обрывается
ipconfig /all, ip a — свой адрес, шлюз, DNS
ipconfig /release + /renew — перезапросить DHCP
ipconfig /flushdns — сбросить кэш имён
arp -a — соответствие IP и MAC
netstat -an — открытые соединения и порты
nslookup ya.ru — что отвечает DNS
Порядок разбора: свой адрес → шлюз → DNS → внешний узел. Обрыв ищется в этом же порядке, а не наугад.
