Базові команди Cisco IOS

enable — привілейований режим
configure terminal — режим конфігурації
hostname R1 — ім'я пристрою
interface gi0/0 — перейти до інтерфейсу
ip address 192.168.1.1 255.255.255.0
no shutdown — підняти інтерфейс
ip route 0.0.0.0 0.0.0.0 10.0.0.1 — маршрут за замовчуванням
show ip interface brief — що піднято і з якими адресами
show running-config — поточна конфігурація
copy running-config startup-config — зберегти
show ip route — таблиця маршрутизації
show mac address-table — таблиця MAC комутатора
vlan 10 / name Class — створити VLAN
switchport mode access / switchport access vlan 10
switchport mode trunk — транк між комутаторами

Діагностика з робочої станції

ping 8.8.8.8 — чи є зв'язок узагалі
ping ya.ru — чи працює DNS
tracert / traceroute — на якому вузлі обривається
ipconfig /all, ip a — своя адреса, шлюз, DNS
ipconfig /release + /renew — перезапитати DHCP
ipconfig /flushdns — скинути кеш імен
arp -a — відповідність IP і MAC
netstat -an — відкриті з'єднання та порти
nslookup ya.ru — що відповідає DNS
Порядок розбору: своя адреса → шлюз → DNS → зовнішній вузол. Обрив шукається в тому самому порядку, а не навмання.
