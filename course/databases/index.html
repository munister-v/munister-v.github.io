Бази та сховища даних

Повний робочий план курсу з проєктування та реалізації реляційних баз даних — від бізнес-вимог і концептуальної моделі до SQL, Oracle APEX і невеликого веб-застосунку поверх бази. Структура повторює Oracle Academy Database Foundations, адаптована українською для самостійного проходження.

Анотація

Бази та сховища даних — курс про те, як дані переходять зі стану «вимоги замовника у вигляді розмови» у стан «робоча реляційна база з обмеженнями цілісності, індексами і запитами». Курс іде по класичному конвеєру проєктування: спочатку бізнес-вимоги і сутності, потім концептуальна модель (ERD), потім логічна модель з нормалізацією, потім фізична реалізація мовою SQL — і насамкінець невеликий веб-застосунок поверх готової бази.

Структура повторює послідовність Oracle Academy Database Foundations (розділи OA 1–6), а лабораторний практикум прив'язаний до інструментів реального стеку Oracle: Oracle SQL Developer Data Modeler для моделювання, Oracle APEX як хмарне середовище виконання SQL і швидкої розробки застосунків. Кожна лекція супроводжується самостійною роботою або лабораторною з фіксованою кількістю балів, а курс завершується індивідуальною консультаційною роботою (веб-застосунок на APEX) та іспитом із двох частин.

Матеріал розрахований на тих, хто раніше не проєктував бази даних, але вже впевнено читає SQL-подібний синтаксис або готовий його освоїти в процесі — теорія завжди йде разом із практичним завданням у тій самій темі.

  • Oracle Academy Database Foundations — офіційна методика, на якій побудований конспект
  • Oracle SQL Developer Data Modeler — ERD, нормалізація, генерація DDL
  • Oracle APEX — хмарне середовище для SQL і веб-сторінок поверх бази
  • SQL: підмови DDL, DML, TCL — від створення об'єктів до транзакцій

Про джерело

Структура, а не контент

Програма складена на основі структури курсу «Бази та сховища даних» (Moodle ДПУ, викл. О. В. Редич), що спирається на офіційну методику Oracle Academy Database Foundations. Авторський контент лекцій, методичок і завдань належить університету та їхнім авторам — тут відтворена лише структура й послідовність тем.
