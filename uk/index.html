Компетенції

Прикладні системи й прототипи

Шари, без яких не працює жодна система: мова, модель даних, інфраструктура та стандарти, що їх поєднують.

Мови програмування

TypeScript, Python, SQL, Swift, а C++ там, де система ближче до заліза.

Фреймворки та інтерфейси

React і Next.js, SwiftUI для iOS, а там, де фреймворк зайвий, чисті HTML, CSS і JavaScript.

Дані та бекенд

Моделювання в PostgreSQL, SQLite та Oracle; сервіси на Flask, REST API та детерміновані конвеєри імпорту.

Інфраструктура та експлуатація

Linux, nginx і TLS, systemd, Docker і GitHub Actions, з резервним копіюванням, закладеним від початку.

Інтеграції та стандарти

LLM API в редакційних процесах, часові пояси, TopoJSON, музейні колекції IIIF, JWT і WebSockets.
