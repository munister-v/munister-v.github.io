Also built

Six more systems in daily use, from retail ERP to a browser radio station.

Mania Group ERP and storefront A WordPress + WooCommerce shop rebuilt from scratch in Next.js 16, React 19 and TypeScript, running headless against the live WooCommerce Store API so product data and photos stay real without touching the old admin. Size-matrix inventory instead of flat stock counts, price-list import from supplier spreadsheets, and the order pipeline behind it — schema, deploy and all. ↗ EPRIS Showcase Editorial index Public submissions go through an editor's review before anything is placed, then through a standalone Node API with its own systemd unit and its own rate limit — separate from the main journal's deploys. Every image is fetched once and re-hosted locally (Sharp, capped at 1400px) so the vitrine never depends on a submitter's server staying online. ↗ Munister Agency Founder No framework — plain HTML, CSS and JS, four languages through a hand-rolled data-i18n layer, deployed by pushing straight to GitHub Pages. Its US-coverage map computes the working-hour overlap live, per state, from IANA time zones via Intl rather than hard-coded numbers; the border geometry is a 32 KB simplified TopoJSON built from the US Census atlas. ↗ AM Publishing Platform and radio A React and Vite storefront on GitHub Pages: each title carries an editable list of purchase links instead of one hard-coded retailer, and checkout is moving to Mollie for a single EU dashboard across cards, SEPA and Apple/Google Pay. The radio side is a separate Flask service on the VPS, sharing nothing with the static frontend but the domain. ↗ Radio Winnipeg Browser radio A WebRTC star broadcast — one microphone reaching many listeners who never have to grant a mic permission of their own — signalled over a polling database rather than a dedicated signalling server. No login: a guest profile is issued automatically and a nickname is one click to change. Multiple rooms share a synced "watch together" now-playing state across everyone inside them. ↗ ARM OS Interface experiment One 5,000-line HTML file holding a real window manager — drag, resize, edge-snap, z-order, a dock, Spotlight-style search — with seventeen apps inside it. Some are iframes onto the live ARM Bank (login, messenger, admin); the rest are native: a currency converter on live rates, a loan calculator, a rate chart, a QR generator, a text editor that persists to localStorage. ↗
