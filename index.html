Editorial research infrastructure

EPRIS Journal

An independent journal used as a testbed for durable cultural publishing. Its infrastructure models articles, objects, translations and media as linked editorial records, then carries them through validation, review, publication and deployment. The resulting digital passport is not a decorative archive: it establishes provenance, re-use paths and a workable research layer around each publication.

Learning systems · product and technology

TeachEd

A language-teaching workspace that converts planning materials, video and vocabulary into structured classroom objects. The system treats a lesson as an editable sequence of tasks, constraints and outputs rather than a static worksheet: teachers can compose, revise, share and re-use material across boards, exercises and follow-up work. I lead the product model, architecture and release process.

Digital humanities · research, text, interface

Italy Chapter

A bilingual digital-humanities study of Italy’s visual language in proportion, light and material. The interface works as an argument: an atlas, a timeline and controlled side-by-side comparisons make the evidence inspectable rather than leaving it as atmosphere. Research, editorial structure, visual system and implementation are developed as one method.

Virtual museum · curation and engineering

EPRIS Museum

Ten halls, 116 paintings, 84 artists, all public domain and drawn from the Art Institute of Chicago over IIIF. The hang is an argument rather than an alphabet: the route runs through four centuries, each hall carries its own wall length and date span, and every work keeps its author, date and collection of origin. The building itself is written as geometry instead of imported as a model, so a hall is a stable address you can cite.

Munister / Systems register

Applied systems and prototypes

Six further implementations. Each addresses a specific operational constraint through data modelling, computational logic or infrastructure design.

Mania Group Retail operations · data model A headless retail system built around the operational problem WordPress could not resolve: variants, supplier prices and orders need a stable model rather than a collection of product pages. The Next.js and TypeScript layer reads live WooCommerce data without duplicating the legacy admin, represents stock as a size-level matrix, normalises supplier spreadsheets into a price-import pipeline and keeps the order flow traceable from catalogue state to fulfilment. ↗ EPRIS Showcase Editorial ingestion · media reliability A controlled intake pipeline for public cultural submissions. Records pass through an editorial decision state before publication; the API is isolated from the journal release cycle and protected by its own rate limit. Media is normalised once with Sharp and retained locally, removing a common archival failure mode: a published record must not disappear because a contributor’s external image host changes or fails. ↗ Munister Agency Temporal-geographic computation A deliberately lightweight multilingual web system whose central method is computational rather than presentational. The coverage map calculates working-hour overlap by state from IANA time-zone rules via Intl, so daylight-saving changes are resolved from source data rather than maintained by hand. Census geometry is reduced to a 32 KB TopoJSON model, making an evidence-based geographic interface fast enough for an ordinary static deployment. ↗ AM Publishing Publishing operations · distributed services A publication platform designed to keep editorial metadata independent from sales channels. Each title holds a maintained offer set instead of one hard-coded retailer, so regional availability can change without rewriting the publication. The frontend stays static and auditable; transactional checkout and the radio service are separated into purpose-built services, reducing coupling between catalogue, payment and streaming operations. ↗ Radio Winnipeg Real-time media · session coordination A low-friction WebRTC broadcast experiment: one source distributes audio to many listeners while receivers never need microphone permission. Session state is coordinated through a polling data layer rather than a dedicated signalling service, which makes the architecture inspectable and deployable with modest infrastructure. Guest identities and room-level now-playing state test how shared listening can remain synchronous without forcing account creation. ↗ ARM OS Human-computer interaction prototype A browser-based operating-environment prototype used to study how familiar desktop mechanics translate into a financial interface. A single-file window manager implements coordinate state, z-order, resize, snap and search behaviour, then connects seventeen tools through shared interaction rules. The experiment combines embedded live services with native utilities, including rate conversion, loan calculation, charting and persistent local documents. ↗
