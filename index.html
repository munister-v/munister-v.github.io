Competencies

Applied systems and prototypes

The layers a working system needs: language, data model, infrastructure and the standards that connect it.

Languages

TypeScript, Python, SQL, Swift, and C++ where a system sits closer to the machine.

Frameworks and interfaces

React and Next.js, SwiftUI for iOS, and plain HTML, CSS and JavaScript where no framework is needed.

Data and backend

PostgreSQL, SQLite and Oracle modelling; Flask services, REST APIs and deterministic import pipelines.

Infrastructure and operations

Linux, nginx and TLS, systemd, Docker and GitHub Actions, with backups designed in from the start.

Integration and standards

LLM APIs in editorial workflows, time zones, TopoJSON, IIIF museum collections, JWT and WebSockets.
