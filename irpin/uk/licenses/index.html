Застосунок використовує відкриті дані та компоненти. Нижче - що саме й на яких умовах. The app uses open data and components. Below is what and under which terms.

Дані · Data

  • OpenStreetMap - заклади, установи, будинки, під'їзди, укриття, велодоріжки, зупинки, залізниця. © учасники OpenStreetMap, ліцензія ODbL 1.0. Venues, buildings, entrances, shelters, cycle paths, stops, railway. © OpenStreetMap contributors, ODbL 1.0.
  • OpenFreeMap · OpenMapTiles - підкладка мапи. Схема OpenMapTiles - BSD-3-Clause, оформлення - CC BY 4.0; дані © OpenStreetMap. Map base: schema BSD-3-Clause, design CC BY 4.0, data © OpenStreetMap. openfreemap.org, openmaptiles.org
  • ukrainealarm · siren.pp.ua - стан повітряних тривог. Air raid alert status. siren.pp.ua
  • outage-data-ua - графіки відключень світла (ДТЕК). Power outage schedules. github.com/Baskerville42/outage-data-ua
  • Вікідані · Wikidata - факти про пам'ятки, ліцензія CC0. Facts about sights, CC0. wikidata.org
  • Open-Meteo - висоти точок для профілю маршрутів, ліцензія CC BY 4.0. Terrain elevation for route profiles, CC BY 4.0. open-meteo.com
  • Overpass API - дані OpenStreetMap про окремі будинки на запит (overpass-api.de, overpass.private.coffee, maps.mail.ru). OpenStreetMap data for single buildings on request, © OpenStreetMap contributors, ODbL 1.0.
  • Київський метрополітен - службові повідомлення з публічного каналу t.me/kyivmetroalerts. Kyiv Metro service notices from its public channel.
  • Ірпінська міська рада, poizdato.net, EasyWay, «Дія» - розклади, перелік послуг, інтервали (довідкові відомості, зібрані вручну з відкритих сторінок). Timetables, service list and intervals compiled by hand from public pages.
